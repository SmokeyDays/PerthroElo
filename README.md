# PerthroElo

A light, easy, highly customizable CMD rating software.

**Play with PerthroElo, All Rating, No Gambling!**
**关注 PerthroElo 谢谢喵，用 Rating 制止你的朋友们玩牌赌钱吧！**

## Get Start

You should

```
pip install git+https://github.com/djcunningham0/multielo.git
```

for requirements.

Other potential requirements:

```
pip install plotext
pip install datetime
```

```
python ./elo.py
```
to get start.


### Usages
First, select a appropriate Rating System

Second, Register Players

Third, Record Match

Finally, Save and Exit

## Features
- Elo with rankings.
- Elo with chips.
- Gaming history.
- Rank list
- Customizable title system
- Edit config to add more games
